# Floor 7

Micah's all-in-one trading platform. Works on iPhone, iPad and PC.

## Put it online with GitHub Pages

1. Create a new repository on GitHub called `floor7`.
2. Upload every file and the `icons` folder from this zip (keep the same layout).
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, then **Save**.
4. After a minute, open `https://<your-username>.github.io/floor7/`.

## Add it to your home screen

- **iPhone / iPad:** open the link in Safari → Share → **Add to Home Screen**.
- **PC:** open it in Chrome or Edge → the install icon in the address bar.

## What's in version 1 (stage 1)

- P&L calendar home (Mon–Fri + week totals), in USD
- Log trades from an MT5 entry screenshot (free on-device reader) with a check-and-confirm step, or enter manually
- Close trades with Hit TP / Hit SL / Closed early; P&L and R worked out automatically (EURUSD, commission per lot)
- Day view, journal with filters, prop accounts (profit target, daily loss left, max drawdown left)
- Notes with typing plus Apple Pencil / mouse drawing
- USD to GBP converter, light/dark mode, export and import a backup
